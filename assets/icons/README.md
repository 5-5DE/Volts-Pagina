# Iconos de Volts

Iconos descargados de [Lucide](https://lucide.dev/icons), desde su repositorio oficial:
https://github.com/lucide-icons/lucide

Revisión de origen: `03eae6069edfc373673bd05d723491f05ba936e3`.
Ruta de descarga: `https://raw.githubusercontent.com/lucide-icons/lucide/03eae6069edfc373673bd05d723491f05ba936e3/icons/{nombre}.svg`.

Se utilizan `plug`, `zap`, `shield-check`, `message-circle-question-mark`,
`arrow-up-right`, `arrow-right`, `chevron-down`, `plus`, `user-round` y `log-out`.

Los trazados originales se conservan. Se ajustó únicamente el color del trazo a
amarillo (`#edbf4a`); los archivos con sufijo `-oscuro` usan `#151718` para los
botones con fondo amarillo. Las páginas los cargan como imágenes con `<img>`.

La licencia y los avisos de Lucide y Feather están en `LICENSE-lucide.txt`.
El PNG que ya existía en esta carpeta es un recurso independiente.
